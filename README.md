# 倉庫番ミニ

ブラウザで遊べるシンプルな倉庫番風パズルゲームです。

現在は 100 ステージを収録しています。

## 起動方法

## フォルダの場所

このプロジェクトのフォルダは次です。

```
/workspace/isao
```

ターミナルでは以下で移動できます。

```bash
cd /workspace/isao
```

表示を確認したい場合は、次を実行します。

```bash
pwd
ls /workspace
```

- `pwd` で今いる場所が `/workspace/isao` と表示されます。
- `ls /workspace` で `isao` フォルダが表示されます。

### 方法1: そのままブラウザで開く（最短）

1. このフォルダの `index.html` をダブルクリック
2. ブラウザでゲーム画面が開いたら、すぐ遊べます

### 方法2: ローカルサーバーで起動する（推奨）

ターミナルでこのリポジトリに移動して、以下を実行:

```bash
python3 -m http.server 8000
```

次にブラウザで以下へアクセス:

- <http://localhost:8000>

終了するときはターミナルで `Ctrl + C`。

## 遊び方

1. PC: 矢印キーまたは `WASD` でプレイヤーを移動
2. スマホ: 画面下の方向ボタン（▲◀▼▶）で移動
3. 箱を押して、すべてのゴール（⭐）へ運ぶ
4. すべて配置できたらステージクリア

## ファイル構成

- `index.html` … 画面レイアウト
- `styles.css` … 見た目
- `script.js` … ゲームロジック
