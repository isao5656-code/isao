# フリック入力練習アプリ

ブラウザで動く、**スマホ対応前提**のフリック入力練習アプリです。

## ルール

- 30秒の間に表示される単語を、1文字ずつフリック入力で完成させます。
- 正しい文字を順番に入力すると単語クリア。
- 単語クリア時のポイント:
  - 文字数ボーナス（長い単語ほど高得点）
  - 速度ボーナス（素早く入力するほど高得点）
- ミスタイプ時は減点があります。
- ハイスコアは `localStorage` に保存され、次回起動時も表示されます。

## スマホ向け調整

- モバイルファーストの画面レイアウト（小さい画面から最適化）。
- 画面下部の操作ボタン固定（親指で押しやすい）。
- キーは通常のスマホ入力に近い 3列×4行 配置（12キー）。
- キーはタップしやすいサイズ・正方形比率を維持。
- タッチ端末はフリック判定のしきい値を最適化。
- 対応端末ではバイブレーションで入力フィードバック。

## 使い方

1. `index.html` をスマホブラウザで開く
2. 「スタート」を押す
3. お題単語をフリック入力する
4. 制限時間終了時にスコアとハイスコアを確認する

## ローカル起動例

```bash
python3 -m http.server 4173
```

その後 `http://localhost:4173` にアクセス。
